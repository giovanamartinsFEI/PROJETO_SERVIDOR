# Projeto Blog - Primeiro Contato com Desenvolvimento Web

Este repositório armazena o código de uma aplicação web estruturada no formato de um blog dinâmico, contendo múltiplas páginas navegáveis e um ambiente interativo para o consumo de conteúdos e postagens.

Este foi o primeiro projeto acadêmico que desenvolvi na faculdade, marcando o meu primeiro contato oficial com o universo da programação e servindo como base fundamental para o início dos meus estudos na área.

---

## Recursos e Páginas

O site foi estruturado para simular a experiência de um blog real, contando com:
* Página Inicial: Apresentação da plataforma e destaques dos conteúdos principais.
* Páginas de Conteúdo: Áreas dedicadas para a leitura individualizada de artigos e postagens.
* Navegação Fluida: Sistema de links que conecta todas as seções de maneira intuitiva para o usuário.
* Estrutura de Servidor: Integração com um ambiente de backend para processar as requisições das páginas e gerenciar o funcionamento da aplicação.

---

## Evolução de Habilidades

Por ser o primeiro projeto da graduação, o foco principal foi a construção de uma base sólida na Web de forma prática, onde pude desenvolver habilidades em:
* Estruturação de layouts limpos e semânticos.
* Estilização visual, alinhamento de elementos e responsividade.
* Lógica de programação aplicada ao navegador para criar interatividade.
* Entendimento inicial sobre o funcionamento de servidores e a comunicação entre o cliente e a aplicação.

---

## Tecnologias Utilizadas

O projeto foi construído utilizando o conjunto fundamental de tecnologias para a web:
* HTML: Para a marcação e estruturação de todos os textos, imagens e seções das páginas.
* CSS: Para a identidade visual, cores, tipografia e organização do design do site.
* JavaScript: Para a implementação de comportamentos dinâmicos e interações na tela.
* Ambiente de Servidor: Tecnologia de backend responsável por rodar a aplicação e servir as páginas de forma estruturada.

---

## Como Executar o Projeto

Como a aplicação depende de um servidor para funcionar corretamente:

1. Baixe ou clone os arquivos deste repositório.
2. Certifique-se de ter o ambiente de execução correspondente ao servidor instalado em sua máquina.
3. Inicie o servidor local através do terminal na pasta do projeto.
4. Abra o navegador e acesse o endereço local indicado (ex: `http://localhost`) para interagir com o blog.
